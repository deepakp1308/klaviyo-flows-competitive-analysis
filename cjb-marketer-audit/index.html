Launch Readiness Verdict

Neither flow could be launched.

As expert marketers attempting to build and launch two common automation flows (welcome series, lead nurture), we encountered 3 launch blockers, 5 usability issues, and 2 structural barriers that prevented confident activation. The flows remain in Draft after a complete attempt.

Methodology

Approach: N=1 qualitative walkthrough from expert marketer persona. Two flows built on live Mailchimp account (Goodnight Fox, us17 datacenter). All screenshots captured from live browser session. Flows saved as Draft only — never activated. Test contacts: deepakkumarp13@gmail.com, deepak_kumar2@intuit.com.

Personas: (A) E-commerce SMB building welcome → first purchase series. (B) Professional services building lead nurture → consultation booking.

Taxonomy: Issues mapped to 8-stage CJB workflow (Discover → Define → Design → Compose → Target → Validate → Activate → Monitor). Classification: Barrier (blocks getting started), Usability (slows progress), Launch-blocker (prevents confident activation).

Automations List — Starting Point

01 Automations Dashboard — Draft flows visible Pass
Marketer goal
See all automation flows, find Draft journeys, understand status
What we see
Automations page lists flows with Draft badges, audience selector set to Goodnight Fox, "Build from scratch" and "Choose flow template" buttons visible
Usability: Template recommendations skew e-commerce

Recommended templates: "Welcome new contacts," "Recover abandoned carts," "Recover lost customers." No ProServ/appointment/nurture templates visible. Expert marketers building B2B or service flows must start from scratch every time.

04 Trigger Picker — No search, category tabs only P1 Barrier
Marketer goal
Quickly find the right trigger for their use case
What's wrong
No search/filter. 6 category tabs with long card lists. Expert marketers who know what trigger they want (e.g., "tag added") must browse through every tab to find it.
P1 Barrier: Trigger Selection List Not Searchable

Impact: Every new flow starts here. An expert marketer building their 10th flow still has to browse category tabs instead of typing "tag" or "signup." This is a known HVC theme. Popular tab also skews e-commerce (Buys any product, Abandoned cart) — ProServ marketers see nothing relevant on first view.

Launch impact: BLOCKS discovery for non-obvious triggers. Slows all flow creation.

05 Time Delay — Set to 2 days (default was 1 week) P2 Usability
Marketer goal
Add 2-day wait between welcome email and follow-up
What happened
Default delay was 1 week (7 days). Had to manually change to 2 days. No guidance on recommended delays for welcome series.
P2 Usability: Delay defaults to 1 week

Welcome series best practice is 1–3 day spacing. A 7-day default means expert marketers who miss this setting ship a welcome series where the second email arrives a week late. No contextual recommendation based on flow type.

06 Email Step — Legacy vs New Builder fork P2 Launch-Blocker
Marketer goal
Design the welcome email content
What's wrong
Modal shows email config (subject, from, schedule) plus a builder selection choice at the bottom. "Select a builder to design your email" presents two visual options. This is the Legacy vs New Email Builder (NEB) fork.
P2 Launch-Blocker: CJB Still Uses Legacy Editor

Impact: Automation emails force a builder choice that doesn't exist in regular campaigns (which default to NEB). Expert marketers trained on the new builder face a different editing experience inside CJB. The campaign wizard feels disconnected from the journey canvas. Content stalls here because the editing context switch is jarring.

Launch impact: BLOCKS content completion → incomplete emails → cannot Turn On.

Usability: Email modal blocks canvas interaction

While this modal is open, "Save and close flow" and canvas clicks are blocked. Must explicitly Close this modal before saving. No auto-save.

Flow B: ProServ Lead Nurture → Appointment

Flow: Scrawler_ProServ_LeadNurture_Appointment · Builder ID: 9172 · Trigger: Tag added (scrawler-proserv-lead)

07 ProServ Flow Canvas — Minimal journey (trigger + 1 email) Incomplete
Marketer goal
Build 3-email nurture: intro → value content → book consultation CTA
What was built
Only trigger + 1 email shell. Content not configured. Delays and additional emails not added. Journey is structurally incomplete.
Launch-Blocker: Incomplete journey cannot be activated

The combination of builder friction (step 06), overlay blocking (canvas clicks intercepted by modals), and lack of progress indicators meant the ProServ flow was abandoned with only the skeleton complete. A marketer who hits these barriers repeatedly will abandon CJB.

08 Tag Trigger Detail — scrawler-proserv-lead P2 Usability
Marketer goal
Configure tag-based trigger for lead nurture entry
What happened
Tag created successfully via combobox. But the tag dropdown shows the entire tag list (100+ tags in this account). No search within the dropdown. Radio button clicks were intercepted by overlays during the original setup pass.
P2 Usability: Tag selector shows full unsorted list

Accounts with many tags face a long scroll through the combobox. Creating a new tag works, but finding an existing tag requires scanning the entire list. Combined with click-intercept issues on radio buttons, this slows trigger configuration for power users.
